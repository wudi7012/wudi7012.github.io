# 初次转换验收（2026-11-03）

`zh.json` 对比指定中文原稿与 LaTeX 重建 PDF，`en.json` 对比用户最终确认的英文 PDF 与整理后的源码构建结果。两者在 MuPDF 四种 DPI 和 Poppler 300 DPI 下均为零像素差异，提取文字也相同。

中文页的字体数据、头像数据和绘制指令也一致。英文第二页的一项嵌入字体二进制数据比较为 false，但绘制指令、提取文字和所有渲染对比一致；英文源码内容未改变。报告没有把 PDF 文件哈希不相同写成“逐字节一致”。

报告记录的是初次生成文件的哈希；后续重编译可能因时间戳变化而产生新的 PDF 哈希。运行 `make verify` 可为当前构建重新生成报告到 `build/`。
